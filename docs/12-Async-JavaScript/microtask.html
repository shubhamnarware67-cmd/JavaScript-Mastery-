Microtask

✅ Complete

Definition

A microtask is a short async task — primarily Promise callbacks (.then, .catch, .finally) and queueMicrotask() — that the event loop always executes before moving on to the next macrotask.

Why Microtasks Matter

They guarantee that Promise resolutions happen as soon as possible — right after the current synchronous code — rather than waiting behind other queued events like timers.

Syntax

Promise.resolve().then(() => console.log("microtask"));
queueMicrotask(() => console.log("also a microtask"));

Examples

// Beginner
console.log("1");
Promise.resolve().then(() => console.log("2"));
console.log("3");
// 1, 3, 2

// Advanced: microtask starvation
function infiniteMicrotasks() {
  Promise.resolve().then(infiniteMicrotasks); // starves macrotasks!
}

Diagrams

Microtask Queue (FIFO, drained completely each cycle): [ .then() callback A ] → [ .then() callback B ] → [ queueMicrotask C ] all run before the next macrotask begins

Internal Working

The microtask queue is drained completely — including any new microtasks scheduled while draining — before the event loop is allowed to process even one macrotask.

Common Mistakes

  • Assuming microtasks and macrotasks have equal priority.
  • Creating unbounded microtask chains that delay rendering or timers indefinitely.
  • Forgetting that async function code before the first await runs synchronously.

Summary

Microtasks — mainly Promise callbacks — form a high-priority queue that the event loop fully drains before handling the next macrotask.
