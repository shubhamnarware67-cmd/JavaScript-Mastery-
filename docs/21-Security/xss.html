XSS

✅ Complete

Definition

XSS (Cross-Site Scripting) is an attack where malicious JavaScript is injected into a trusted page and executed in other users' browsers.

Why XSS Matters

A successful XSS attack can steal session cookies, log keystrokes, redirect users to phishing pages, or perform actions as the victim.

Syntax

// Vulnerable
element.innerHTML = userComment; // executes if malicious

// Safe
element.textContent = userComment;

Examples

import DOMPurify from "dompurify";
element.innerHTML = DOMPurify.sanitize(userHtmlInput);

Diagrams

Untrusted input ──► rendered directly as HTML │ Browser PARSES it as real HTML/JS │ Malicious script EXECUTES

Internal Working

The vulnerability is the browser's inability to distinguish trusted markup from untrusted data that looks like markup — escaping prevents parsing as executable HTML.

Common Mistakes

  • Using innerHTML, document.write(), or eval() with untrusted input.
  • Assuming client-side validation alone is sufficient.
  • Using dangerouslySetInnerHTML without sanitizing content.

Summary

XSS lets attackers inject and execute malicious scripts by exploiting improperly escaped input — defended against by treating untrusted data as text and using sanitization libraries.
