### Performance {#performance}
1. Which API measures precise elapsed time? (a) `Date.now()` only (b) **`performance.now()`** (c) `setTimeout()` (d) `console.log()` → **(b)**
2. Core Web Vitals include: (a) CPU usage (b) **LCP, INP, CLS** (c) RAM size (d) Screen resolution → **(b)**

### Debounce {#debounce}
1. A debounced function set to run 300ms after the last call means: (a) Runs every 300ms regardless (b) **Only runs once calls stop for 300ms** (c) Runs immediately every time (d) Runs exactly once ever → **(b)**
2. Debounce is ideal for: (a) Continuous scroll tracking (b) **Search-as-you-type input** (c) Animation frames (d) Infinite scroll → **(b)**

### Throttle {#throttle}
1. A throttled function with a 200ms limit runs: (a) Only once ever (b) **At most once every 200ms** (c) Only after the event stops (d) Immediately every time → **(b)**
2. Throttle is ideal for: (a) Search input (b) **Continuous scroll/resize events** (c) Form submission (d) One-time API calls → **(b)**

### Lazy Loading {#lazy-loading}
1. Which HTML attribute enables native lazy loading for images? (a) `defer` (b) `async` (c) **`loading="lazy"`** (d) `preload` → **(c)**
2. Lazy loading JS modules is achieved via: (a) `require()` (b) **Dynamic `import()`** (c) `<script defer>` (d) `eval()` → **(b)**

### Tree Shaking {#tree-shaking}
1. Tree shaking primarily relies on: (a) Minification (b) **Static analysis of ES Module import/export** (c) Runtime profiling (d) Gzip compression → **(b)**
2. Tree shaking works reliably with: (a) CommonJS (b) **ES Modules** (c) Global scripts (d) Inline styles → **(b)**
