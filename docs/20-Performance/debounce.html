Debounce

✅ Complete

Definition

Debouncing delays executing a function until a specified time has passed without the triggering event firing again — resetting the timer on every new call.

Why Debounce Matters

It prevents functions from running excessively during rapid-fire events, which can otherwise cause performance issues or unnecessary API calls.

Syntax

function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

Examples

const debouncedSearch = debounce((query) => {
  console.log("Searching for:", query);
}, 300);

input.addEventListener("input", (e) => debouncedSearch(e.target.value));

Diagrams

Keystroke 1 ──► timer set for 300ms Keystroke 2 (before timer fires) ──► timer CLEARED and reset Keystroke 3 (before timer fires) ──► timer CLEARED and reset ... 300ms of silence ──► function FINALLY runs, once

Internal Working

Debounce uses closures to maintain a single timer variable — each new call clears the previous pending timeout and schedules a new one.

Common Mistakes

  • Confusing debounce with throttle.
  • Forgetting to clear the timer on unmount, causing calls after the component is gone.
  • Setting the delay too high, making the UI feel unresponsive.

Summary

Debounce delays execution until a burst of calls has settled — ideal for search-as-you-type and auto-save patterns.
