# Browser Storage — MCQs

> Owner: **Shubham Narware** · Status: ✅ Complete

### LocalStorage {#localstorage}
1. Data in `localStorage` persists: (a) Only for current tab (b) Only until browser closes (c) **Until explicitly cleared, even after restart** (d) For 24 hours only → **(c)**
2. `localStorage` can natively store: (a) Any object (b) **Only strings** (c) Functions (d) DOM elements → **(b)**

### SessionStorage {#sessionstorage}
1. `sessionStorage` data is cleared when: (a) Page refreshed (b) 24 hours pass (c) **Tab/window closed** (d) Never → **(c)**
2. Two tabs on the same site have: (a) Shared `sessionStorage` (b) **Independent `sessionStorage`** (c) No storage at all (d) Shared `localStorage` only → **(b)**

### Cookies {#cookies}
1. Which flag prevents JS from reading a cookie? (a) `Secure` (b) **`HttpOnly`** (c) `SameSite` (d) `path` → **(b)**
2. Approximate cookie size limit: (a) 1MB (b) **4KB** (c) 10MB (d) Unlimited → **(b)**

### IndexedDB {#indexeddb}
1. Compared to `localStorage`, IndexedDB is: (a) Synchronous, string-only (b) **Asynchronous, supports structured objects** (c) Only for cookies (d) Limited to 5KB → **(b)**
2. IndexedDB operations are wrapped in: (a) Callbacks only (b) **Transactions** (c) Cookies (d) Global variables → **(b)**
