Scope

✅ Complete

Definition

Scope defines the region of code where a particular variable or function is accessible.

Why Scope Matters

It prevents naming collisions, controls what parts of code can read/modify a variable, and is foundational to closures and module encapsulation.

Syntax

function outer() {
  let x = 10; // function-scoped to outer()
  if (true) {
    let y = 20; // block-scoped to this if block
  }
  // y is not accessible here
}

Examples

for (var i = 0; i < 3; i++) {}
console.log(i); // 3 — var leaks outside the loop's block

for (let j = 0; j < 3; j++) {}
console.log(typeof j); // "undefined" — j is block-scoped

Diagrams

Global Scope └── Function Scope (outer) └── Block Scope (if/for/while) let/const invisible outside; var leaks up

Internal Working

var is function-scoped, while let/const are block-scoped — this is why a var inside an if block "leaks" outside it.

Common Mistakes

  • Using var inside loops expecting each iteration to have its own value.
  • Assuming block scope applies to var like let/const.
  • Creating unintentional global variables by forgetting a declaration keyword.

Summary

Scope determines where a variable is visible — var is function-scoped, while let/const are block-scoped, forming the basis for closures and encapsulation.
