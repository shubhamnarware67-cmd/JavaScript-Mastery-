Promise

✅ Complete

Definition

A Promise is an object representing the eventual completion (or failure) of an asynchronous operation, existing in one of three states: pending, fulfilled, or rejected.

Why Promises Matter

They provide a cleaner, chainable way to handle async operations and their errors, compared to deeply nested callbacks.

Syntax

const promise = new Promise((resolve, reject) => {
  if (success) resolve(value);
  else reject(error);
});
promise.then(onFulfilled).catch(onRejected).finally(onDone);

Examples

const promise = new Promise((resolve) => {
  setTimeout(() => resolve("Data loaded!"), 1000);
});
promise.then(result => console.log(result));

Diagrams

Promise states: pending ──resolve()──► fulfilled ──► .then() callbacks run │ └──reject()──► rejected ──► .catch() callbacks run

Internal Working

A Promise's executor function runs synchronously when created, but its .then()/.catch() callbacks are always scheduled as microtasks, running after the current synchronous code finishes.

Common Mistakes

  • Forgetting to return a value/Promise inside a .then() chain, breaking the chain.
  • Not adding a .catch(), causing unhandled promise rejections.
  • Nesting .then() calls instead of chaining them flat.

Summary

A Promise represents a future value from an async operation, moving through pending, fulfilled, or rejected states, with .then()/.catch()/.finally() callbacks scheduled as microtasks.
