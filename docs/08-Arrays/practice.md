# Arrays — Coding Practice

> Owner: **Shubham Narware**

### Arrays {#arrays}
- **Easy:** Create an array of 5 numbers, log its length and first/last elements.
- **Medium:** Use destructuring to extract the first 2 items and the rest into a separate array.
- **Hard:** Write a function flattening an arbitrarily nested array without using `.flat()`.

### Map {#map}
- **Easy:** Convert an array of Celsius temps to Fahrenheit using `.map()`.
- **Medium:** Extract a single property from an array of objects using `.map()`.
- **Hard:** Chain `.filter()` and `.map()` to transform/filter a dataset in one pipeline.

### Filter {#filter}
- **Easy:** Filter an array of numbers keeping only values greater than 10.
- **Medium:** Filter an array of user objects keeping only `isActive: true` ones.
- **Hard:** Chain `.filter()`, `.map()`, `.reduce()` to total in-stock products above a price threshold.

### Reduce {#reduce}
- **Easy:** Use `.reduce()` to sum an array of numbers.
- **Medium:** Use `.reduce()` to count occurrences of each value in an array.
- **Hard:** Use `.reduce()` to group an array of objects by a property.

### Sort {#sort}
- **Easy:** Sort an array of numbers ascending correctly (with a compare function).
- **Medium:** Sort an array of objects by a date property, oldest first.
- **Hard:** Sort strings case-insensitively without mutating the original array.

### Splice {#splice}
- **Easy:** Use `.splice()` to remove the 3rd element of an array.
- **Medium:** Use `.splice()` to insert 2 new elements into the middle of an array.
- **Hard:** Write `removeById(array, id)` using `findIndex()` + `.splice()`.

### Slice {#slice}
- **Easy:** Use `.slice()` to get the last 3 elements of an array.
- **Medium:** Write `paginate(items, page, pageSize)` using `.slice()`.
- **Hard:** Demonstrate the shallow-copy pitfall of `.slice()` on objects, then fix with a deep copy.
