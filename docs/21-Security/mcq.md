### Security {#security}
1. Which policy restricts scripts from one origin accessing another by default? (a) CORS (b) CSP (c) **Same-Origin Policy** (d) HTTPS → **(c)**
2. Safer way to render untrusted content: (a) `innerHTML` (b) **`textContent`** (c) `document.write()` (d) `eval()` → **(b)**

### CORS {#cors}
1. CORS is enforced by: (a) The server, blocking the request entirely (b) **The browser, blocking the response from reaching JS** (c) DNS servers (d) Firewalls only → **(b)**
2. Preflight requests use method: (a) GET (b) POST (c) **OPTIONS** (d) HEAD → **(c)**

### CSRF {#csrf}
1. CSRF attacks specifically exploit: (a) SQL injection (b) **Browsers automatically attaching cookies** (c) Weak passwords (d) DNS spoofing → **(b)**
2. Which cookie attribute helps prevent CSRF? (a) `HttpOnly` (b) **`SameSite`** (c) `path` (d) `domain` → **(b)**

### XSS {#xss}
1. Which XSS type saves the payload server-side permanently? (a) Reflected (b) **Stored** (c) DOM-based (d) None → **(b)**
2. React's raw HTML API is named: (a) `setInnerHTML` (b) **`dangerouslySetInnerHTML`** (c) `renderHTML` (d) `rawHTML` → **(b)**
