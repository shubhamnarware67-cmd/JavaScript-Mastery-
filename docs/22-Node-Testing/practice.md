# Node & Testing — Coding Practice

> Owner: **Shubham Narware** · Status: ✅ Complete

### Node.js {#nodejs}
1. **(Easy)** Write a Node.js script that reads a text file and logs its contents.
2. **(Medium)** Build a simple HTTP server using the built-in `http` module with path-based responses.
3. **(Hard)** Build a custom `EventEmitter`-based class emitting events at stages of an order-processing pipeline.

### Express {#express}
1. **(Easy)** Build a basic Express server with a `GET /` route returning JSON.
2. **(Medium)** Write logging middleware that logs each request's method and URL.
3. **(Hard)** Build a small REST API with `express.Router()` for a `/products` resource (GET, POST, DELETE).

### Testing {#testing}
1. **(Easy)** Write a unit test for a simple `add(a, b)` function.
2. **(Medium)** Write a test for an async function using `async/await`.
3. **(Hard)** Write a test that mocks a dependency to isolate the function under test.

### Jest {#jest}
1. **(Easy)** Write a Jest test using `describe`/`test` for a utility function.
2. **(Medium)** Write a test using `jest.mock()` to isolate a function from an external dependency.
3. **(Hard)** Write tests for an async function using both `async/await` and `.resolves`/`.rejects`.

### Chrome DevTools {#chrome-devtools}
1. **(Easy)** Use `console.table()` to log an array of objects.
2. **(Medium)** Set a breakpoint in Sources and step through a function inspecting variables.
3. **(Hard)** Take two heap snapshots around a suspected leak and describe how you'd compare them.
