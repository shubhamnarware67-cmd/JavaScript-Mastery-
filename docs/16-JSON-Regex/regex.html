Regex

✅ Complete

Definition

Regular expressions (regex) are patterns used to match, search, and manipulate text — represented by the RegExp object or /pattern/flags literal syntax.

Why Regex Matters

It provides a compact, powerful way to validate input, search/replace text patterns, and extract structured data from strings.

Syntax

const pattern = /hello/i;
const pattern2 = new RegExp("hello", "i");
pattern.test("Hello World"); // true

Examples

const emailPattern = /^[\w.-]+@[\w.-]+\.\w+$/;
console.log(emailPattern.test("user@example.com")); // true

const datePattern = /(?\d{4})-(?\d{2})-(?\d{2})/;
const match = "2026-07-23".match(datePattern);
console.log(match.groups.year); // "2026"

Diagrams

/pattern/flags │ Compiled into an internal matching engine (NFA-based) │ .test(str) ──► boolean .exec(str) / str.match(pattern) ──► match details

Internal Working

JavaScript regex engines are typically backtracking-based (NFA) — certain patterns can suffer from catastrophic backtracking, a real security concern known as ReDoS.

Common Mistakes

  • Using .exec() in a loop with the g flag but forgetting it maintains internal state.
  • Writing overly complex regex without comments, making it hard to maintain.
  • Not escaping special characters when building a pattern dynamically from user input.

Summary

Regex provides a compact, powerful pattern-matching language for validating, searching, and extracting text — useful, but requiring care around readability and performance.
