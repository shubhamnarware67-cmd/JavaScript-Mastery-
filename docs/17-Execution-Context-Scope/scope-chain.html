Scope Chain

✅ Complete

Definition

The scope chain is the ordered list of scopes JavaScript searches — from innermost to outermost — when resolving a variable reference.

Why Scope Chain Matters

It explains how nested functions can access variables from enclosing functions (closures), and why lookups fail only after checking every level.

Syntax

const outer = "I'm outer";
function middle() {
  const inner = "I'm inner";
  function innermost() {
    console.log(outer); // found by walking UP the scope chain
    console.log(inner);
  }
  innermost();
}

Examples

function makeMultiplier(factor) {
  return function (n) {
    return n * factor; // `factor` found via scope chain — a closure
  };
}
const double = makeMultiplier(2);
console.log(double(5)); // 10

Diagrams

innermost() scope ──► { } │ (not found, look up) middle() scope ──► { inner: "I'm inner" } │ (not found, look up) Global scope ──► { outer: "I'm outer" }

Internal Working

The scope chain is fixed at the time a function is defined (lexical scoping), not when it's called.

Common Mistakes

  • Assuming scope is determined by the call site (dynamic scoping) rather than definition site.
  • Shadowing an outer variable and being surprised which value is used.
  • Not realizing closures work because of the scope chain persisting after the outer function returns.

Summary

The scope chain is the lexical path JavaScript follows to resolve variables — searching the current scope first, then each enclosing scope — forming the mechanism behind closures.
