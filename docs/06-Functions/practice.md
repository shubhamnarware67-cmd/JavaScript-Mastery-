# Functions — Coding Practice

> Owner: **Shubham Narware**

### Functions {#functions}
- **Easy:** Write a function that returns the square of a number.
- **Medium:** Write a function accepting another function as an argument, calling it on each array element.
- **Hard:** Write a function factory generating specialized functions (e.g. `multiplier(factor)`).

### Arrow Function {#arrow-function}
- **Easy:** Convert 3 regular function expressions into arrow functions.
- **Medium:** Fix a `this`-related bug in a `setTimeout` callback inside an object method using an arrow function.
- **Hard:** Explain/demonstrate why an arrow function can't serve as an object method needing its own `this`.

### Callback {#callback}
- **Easy:** Write a function taking a callback, calling it with a greeting message.
- **Medium:** Write a function using the error-first callback convention simulating a data fetch that might fail.
- **Hard:** Write 3 levels of nested callbacks simulating "callback hell," noting how Promises would flatten it.

### Closure {#closure}
- **Easy:** Write a `counter()` closure function incrementing/returning a count each call.
- **Medium:** Build a `bankAccount` object using closures for private `balance`.
- **Hard:** Implement a simple memoization utility using a closure-based cache.

### Currying {#currying}
- **Easy:** Write a curried `multiply(a)(b)` function.
- **Medium:** Write a curried 3-argument `volume(l)(w)(h)` function.
- **Hard:** Implement a generic `curry(fn)` utility working for any function's argument count.

### Memoization {#memoization}
- **Easy:** Write a `memoize()` utility caching results for a single-argument function.
- **Medium:** Use memoization to speed up a naive recursive Fibonacci implementation.
- **Hard:** Extend `memoize()` to support multi-argument functions via a serialized cache key.
