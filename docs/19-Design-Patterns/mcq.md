# Design Patterns — MCQs

> Owner: **Shubham Narware** · Status: ✅ Complete

### Design Patterns {#design-patterns}
1. Which category does Singleton belong to? (a) Structural (b) Behavioral (c) **Creational** (d) Architectural → **(c)**
2. Which category does Observer belong to? (a) Creational (b) **Behavioral** (c) Structural (d) None → **(b)**

### Singleton {#singleton}
1. A key characteristic of Singleton is: (a) Multiple instances allowed (b) **Exactly one instance exists** (c) No instances ever created (d) Recreated on every call → **(b)**
2. ES Modules provide singleton-like behavior because: (a) They run multiple times (b) **Top-level code runs only once, cached** (c) They can't export objects (d) They require classes → **(b)**

### Factory {#factory}
1. The main benefit of a Factory function is: (a) Faster performance (b) **Encapsulating and centralizing creation logic** (c) Making objects immutable (d) Removing objects entirely → **(b)**
2. Factory functions typically: (a) Require `new` (b) **Can be called without `new`, returning any object shape** (c) Only work with classes (d) Can't have conditional logic → **(b)**

### Observer {#observer}
1. The Observer pattern primarily solves: (a) Object creation (b) **One-to-many state change notification** (c) Memory management (d) Data serialization → **(b)**
2. `addEventListener` is an example of: (a) Singleton (b) Factory (c) **Observer** (d) MVC → **(c)**

### MVC {#mvc}
1. In MVC, which layer directly handles user input? (a) Model (b) View (c) **Controller** (d) None → **(c)**
2. The Model in MVC should: (a) Know about the View (b) **Have no direct knowledge of the View** (c) Handle user clicks directly (d) Render HTML → **(b)**

### MVVM {#mvvm}
1. In MVVM, what keeps the View updated automatically? (a) Manual `render()` calls (b) **Data binding/reactivity system** (c) Page refresh (d) `setTimeout` polling → **(b)**
2. A "computed property" is: (a) A static constant (b) **A derived value recalculated from other properties** (c) A DOM element (d) An HTTP request → **(b)**
