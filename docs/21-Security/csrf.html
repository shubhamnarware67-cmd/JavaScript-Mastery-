CSRF

✅ Complete

Definition

CSRF (Cross-Site Request Forgery) is an attack that tricks a logged-in user's browser into unknowingly sending an authenticated request, exploiting automatic cookie attachment.

Why CSRF Matters

Without protection, a malicious site could silently trigger actions on a site where the victim is already logged in.

Syntax

fetch("/api/transfer", {
  method: "POST",
  headers: { "X-CSRF-Token": csrfToken },
  body: JSON.stringify({ amount: 100 }),
});

Examples

// Set-Cookie: sessionId=abc123; SameSite=Strict; Secure; HttpOnly

Diagrams

Victim logged into bank.com (valid session cookie) │ Victim visits malicious-site.com │ malicious-site.com auto-submits a form to bank.com │ Browser attaches bank.com's cookies automatically │ Without CSRF protection: processed as legitimate

Internal Working

CSRF exploits automatic cookie attachment — a server must verify something the attacker couldn't reproduce, like a per-session CSRF token.

Common Mistakes

  • Relying only on Referer/Origin headers without a CSRF token.
  • Not setting SameSite on session cookies.
  • Using predictable or reused CSRF tokens.

Summary

CSRF tricks a victim's browser into sending unwanted authenticated requests — defended against with CSRF tokens and SameSite cookies.
