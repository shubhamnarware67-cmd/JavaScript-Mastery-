Try Catch

✅ Complete

Definition

try...catch is a JavaScript control structure that lets you attempt code that might throw an error, and gracefully handle that error instead of letting it crash the program.

Why Try Catch Matters

Without it, a single runtime error would stop script execution entirely — try...catch lets you isolate risky code and keep the rest of the program running.

Syntax

try {
  // risky code
} catch (error) {
  // handle error
} finally {
  // always runs, error or not
}

Examples

// Beginner
try {
  const result = 10 / undefinedVar; // ReferenceError
} catch (error) {
  console.log("Caught:", error.message);
}

// Advanced: async/await
async function fetchData(url) {
  try {
    const res = await fetch(url);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (error) {
    console.error("Fetch failed:", error.message);
    throw error;
  }
}

Diagrams

Enter try block │ Error thrown? ──No──► try block completes ──► finally runs │ Yes ▼ Jump to catch block │ catch runs ──► finally runs ──► continue after try/catch

Internal Working

When an error is thrown inside a try block, the JS engine immediately stops executing that block and searches up the call stack for a matching catch.

Common Mistakes

  • Expecting try...catch to catch errors thrown inside setTimeout callbacks.
  • Swallowing errors silently in catch without logging or handling them.
  • Forgetting that finally runs even if try or catch contains a return.

Summary

try...catch (optionally with finally) lets JavaScript gracefully handle runtime errors instead of crashing, with finally guaranteed to run for cleanup regardless of outcome.
