JSON

✅ Complete

Definition

JSON (JavaScript Object Notation) is a lightweight, text-based data format for representing structured data, built into JavaScript via JSON.stringify() and JSON.parse().

Why JSON Matters

It's the universal language for exchanging data between a client and server — nearly every REST API today uses JSON because it's simple, human-readable, and maps directly onto JS objects/arrays.

Syntax

const json = JSON.stringify({ name: "Shubham", age: 25 });
const obj = JSON.parse(json);

Examples

const data = { name: "Alex", password: "secret123", age: 30 };
const safeJson = JSON.stringify(data, (key, value) =>
  key === "password" ? undefined : value
);

const res = await fetch("/api/users");
const users = await res.json();

Diagrams

JS Object (in memory) JSON String (text) { id: 1, name: "Book" } ──stringify──► '{"id":1,"name":"Book"}' { id: 1, name: "Book" } ◄──parse──── '{"id":1,"name":"Book"}'

Internal Working

JSON.stringify() skips undefined, functions, and Symbols when encountered as object properties; JSON.parse() optionally accepts a "reviver" function.

Common Mistakes

  • Assuming JSON.parse(JSON.stringify(obj)) is a perfect deep clone.
  • Forgetting JSON.stringify() throws on circular references.
  • Not handling JSON.parse() errors on malformed strings.

Summary

JSON is the standard lightweight text format for structured data exchange, simple and universal, but limited to a small set of data types.
