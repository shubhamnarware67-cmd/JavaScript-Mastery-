SessionStorage

✅ Complete

Definition

sessionStorage is a browser API that stores key-value string data scoped to a single tab's session — cleared automatically when that tab or window is closed.

Why SessionStorage Matters

It's ideal for data that should only last as long as the current tab is open, without leaking into other tabs or persisting after the tab closes.

Syntax

sessionStorage.setItem("key", "value");
sessionStorage.getItem("key");
sessionStorage.removeItem("key");
sessionStorage.clear();

Examples

sessionStorage.setItem("step", "2");
console.log(sessionStorage.getItem("step")); // "2"

function saveFormProgress(step, data) {
  sessionStorage.setItem(`form-step-${step}`, JSON.stringify(data));
}

Diagrams

Tab A: sessionStorage { step: "2" } ← isolated to this tab Tab B: sessionStorage { } ← empty, even on the same site Closing Tab A ──► its sessionStorage is destroyed

Internal Working

Unlike localStorage, sessionStorage is scoped per browsing context (tab/window) — even two tabs open to the same URL have completely separate sessionStorage.

Common Mistakes

  • Confusing sessionStorage's per-tab scope with localStorage's cross-tab, cross-session scope.
  • Expecting data to survive across different tabs of the same site.
  • Not accounting for closing/reopening the browser creating a fresh, empty sessionStorage.

Summary

sessionStorage offers the same simple API as localStorage, but scoped strictly to a single tab's session — ideal for short-lived, per-tab state.
