Cookies

✅ Complete

Definition

Cookies are small pieces of key-value data stored by the browser and automatically sent to the server with every matching HTTP request.

Why Cookies Matter

They remain the standard way to handle server-side session identification (like login sessions), since they're automatically included in every HTTP request to the matching domain.

Syntax

document.cookie = "username=Shubham; expires=Fri, 31 Dec 2026 23:59:59 GMT; path=/";
console.log(document.cookie);

Examples

function getCookie(name) {
  const match = document.cookie.match(new RegExp(`(^| )${name}=([^;]+)`));
  return match ? match[2] : null;
}

function setCookie(name, value, days) {
  const date = new Date();
  date.setTime(date.getTime() + days * 24 * 60 * 60 * 1000);
  document.cookie = `${name}=${value}; expires=${date.toUTCString()}; path=/; Secure; SameSite=Lax`;
}

Diagrams

Browser cookie jar (per domain): { theme: "dark", sessionId: "abc123" } │ Automatically attached to every matching HTTP request's headers

Internal Working

Cookies are limited to about 4KB each and sent with every matching HTTP request; HttpOnly cookies can't be read via document.cookie, protecting them from XSS.

Common Mistakes

  • Storing large amounts of data in cookies, unnecessarily bloating every HTTP request.
  • Forgetting to set the path attribute, scoping the cookie more narrowly than intended.
  • Not setting Secure/HttpOnly on sensitive cookies.

Summary

Cookies are the oldest browser storage mechanism, automatically attached to every matching HTTP request, ideal for server-recognized session data but a poor choice for large client-only data.
