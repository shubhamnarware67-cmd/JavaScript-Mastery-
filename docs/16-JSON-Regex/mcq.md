### JSON {#json}
1. `JSON.stringify({ a: undefined, b: 1 })` produces: (a) `'{"a":undefined,"b":1}'` (b) **`'{"b":1}'`** (c) Throws an error (d) `'null'` → **(b)**
2. Which JSON method uses a "reviver" function? (a) `.stringify()` (b) **`.parse()`** (c) `.toJSON()` (d) `.encode()` → **(b)**
3. JSON does NOT support: (a) Strings (b) Numbers (c) **Functions** (d) Arrays → **(c)**

### Regex {#regex}
1. Which method returns a boolean for a pattern match? (a) `.exec()` (b) **`.test()`** (c) `.match()` (d) `.replace()` → **(b)**
2. Named capture groups use syntax: (a) `(name)` (b) **`(?<name>...)`** (c) `[name]` (d) `{name}` → **(b)**
3. "Catastrophic backtracking" is primarily a concern for: (a) Short strings only (b) **Performance/security (ReDoS) on certain patterns** (c) JSON parsing (d) Array methods → **(b)**
