### Node.js {#nodejs}
1. Node's non-blocking I/O is enabled by: (a) Multiple V8 instances (b) **libuv's event loop and thread pool** (c) Web Workers (d) The DOM → **(b)**
2. Node.js JS execution is: (a) Multi-threaded (b) **Single-threaded** (c) No threading model (d) GPU-based → **(b)**

### Express {#express}
1. Error-handling middleware has how many parameters? (a) 2 (b) 3 (c) **4** (d) Any number → **(c)**
2. `express.Router()` is used to: (a) Connect to a database (b) **Group and modularize related routes** (c) Parse JSON (d) Handle errors only → **(b)**

### Testing {#testing}
1. Which test verifies a single function in isolation? (a) E2E test (b) **Unit test** (c) Integration test (d) Manual test → **(b)**
2. The testing pyramid recommends: (a) Mostly E2E tests (b) **Many unit tests, few E2E tests** (c) Only integration tests (d) No automated tests → **(b)**

### Jest {#jest}
1. Which matcher checks deep equality for objects/arrays? (a) `.toBe()` (b) **`.toEqual()`** (c) `.toContain()` (d) `.toThrow()` → **(b)**
2. `jest.mock()` is used to: (a) Delete a module (b) **Replace a module with a controllable mock** (c) Run tests faster only (d) Format code → **(b)**

### Chrome DevTools {#chrome-devtools}
1. Which panel inspects HTTP request/response timing? (a) Elements (b) **Network** (c) Memory (d) Application → **(b)**
2. Heap snapshots are used in which panel? (a) Sources (b) Network (c) **Memory** (d) Console → **(c)**
