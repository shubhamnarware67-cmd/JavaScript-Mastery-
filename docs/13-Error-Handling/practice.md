# Error Handling — Coding Practice

> Owner: **Shubham Narware** · Status: ✅ Complete

### Try Catch {#try-catch}
1. **(Easy)** Write a `try...catch` that safely parses JSON and returns `null` on failure.
2. **(Medium)** Write a function that retries a risky operation up to 3 times using `try...catch` in a loop.
3. **(Hard)** Demonstrate why `try...catch` cannot catch an error thrown inside a `setTimeout` callback, and show the correct fix.

### Throw {#throw}
1. **(Easy)** Write a function that throws an `Error` if a given number is negative.
2. **(Medium)** Create a custom error class `NotFoundError` extending `Error` with an extra `statusCode` property.
3. **(Hard)** Build a validation function that throws different custom error subclasses for different invalid inputs, with a caller using `instanceof` to handle each differently.
