Lazy Loading

✅ Complete

Definition

Lazy loading defers loading non-critical resources (images, modules, components) until they're actually needed.

Why Lazy Loading Matters

It reduces initial page load time and bandwidth usage by only fetching what's immediately visible or needed.

Syntax

// Native lazy image loading
// <img src="photo.jpg" loading="lazy" alt="..." />

async function loadChart() {
  const { renderChart } = await import("./chart.js");
  renderChart();
}

Examples

const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      entry.target.src = entry.target.dataset.src;
      observer.unobserve(entry.target);
    }
  });
});
document.querySelectorAll("img[data-src]").forEach((img) => observer.observe(img));

Diagrams

Initial page load: Above-the-fold content ──► loaded immediately Below-the-fold images ──► loaded on scroll-into-view Rarely-used JS modules ──► loaded on dynamic import

Internal Working

IntersectionObserver efficiently detects viewport entry without expensive scroll listeners; dynamic import() creates on-demand-loaded chunks.

Common Mistakes

  • Lazy-loading critical above-the-fold content.
  • Forgetting to unobserve() after loading.
  • Not reserving space, causing layout shift.

Summary

Lazy loading defers non-critical resources until needed, significantly improving initial load performance.
