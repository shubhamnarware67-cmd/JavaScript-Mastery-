### WeakMap {#weakmap}
1. `WeakMap` keys must be: (a) Strings only (b) **Objects only** (c) Any primitive (d) Numbers only → **(b)**
2. `WeakMap` is: (a) Iterable (b) **Not iterable** (c) Always empty (d) Only for arrays → **(b)**

### WeakSet {#weakset}
1. Which can be added to a `WeakSet`? (a) A string (b) A number (c) **An object** (d) `null` → **(c)**
2. `WeakSet` entries are removed: (a) Manually only (b) **Automatically when GC'd** (c) Never (d) After 24 hours → **(b)**

### Proxy {#proxy}
1. Which trap intercepts property assignment? (a) `get` (b) **`set`** (c) `has` (d) `apply` → **(b)**
2. `Proxy` is primarily used for: (a) Faster loops (b) **Intercepting fundamental object operations** (c) String formatting (d) Type conversion → **(b)**

### Reflect {#reflect}
1. `Reflect.has(obj, "x")` is equivalent to: (a) `obj.x` (b) `delete obj.x` (c) **`"x" in obj`** (d) `obj.hasOwnProperty("x")` → **(c)**
2. `Reflect` is most commonly paired with: (a) `Map` (b) **`Proxy`** (c) `Array` (d) `JSON` → **(b)**
