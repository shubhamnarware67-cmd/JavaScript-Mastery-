Throttle

✅ Complete

Definition

Throttling ensures a function executes at most once within a specified time window, regardless of how many times the triggering event fires.

Why Throttle Matters

It guarantees a function runs at a steady, predictable rate during continuous events like scrolling or mouse movement.

Syntax

function throttle(fn, limit) {
  let inThrottle = false;
  return (...args) => {
    if (inThrottle) return;
    fn(...args);
    inThrottle = true;
    setTimeout(() => (inThrottle = false), limit);
  };
}

Examples

const throttledScroll = throttle(() => {
  console.log("Scroll position:", window.scrollY);
}, 200);

window.addEventListener("scroll", throttledScroll);

Diagrams

Internal Working

Throttle uses a boolean flag with setTimeout to enforce a "cooldown" window — unlike debounce, the timer isn't reset on every call.

Common Mistakes

  • Using debounce when throttle is actually needed.
  • Setting the throttle limit too low, negating its performance benefit.
  • Missing the "final" event in a burst without a trailing call.

Summary

Throttle ensures a function executes at most once per fixed window — ideal for continuous events like scrolling where regular execution matters.
