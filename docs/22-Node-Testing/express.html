Express

✅ Complete

Definition

Express is a minimal, unopinionated web framework for Node.js that simplifies building HTTP servers and APIs through routing and middleware.

Why Express Matters

It removes the boilerplate of Node's raw http module — routing and body parsing become simple, declarative code.

Syntax

const express = require("express");
const app = express();
app.get("/users", (req, res) => res.json({ users: [] }));
app.listen(3000);

Examples

const router = express.Router();
router.get("/:id", (req, res) => res.json({ id: req.params.id }));
app.use("/users", router);

// Error handling middleware
app.use((err, req, res, next) => {
  res.status(500).json({ error: err.message });
});

Diagrams

Incoming Request │ Middleware 1 (logging) ──► calls next() │ Middleware 2 (auth check) ──► calls next() │ Matching Route Handler ──► sends response

Internal Working

Express processes requests through a middleware pipeline — each function receives (req, res, next) and must call next().

Common Mistakes

  • Forgetting to call next(), causing requests to hang.
  • Placing route handlers before required middleware like express.json().
  • Not centralizing error handling.

Summary

Express simplifies building Node.js servers through a middleware pipeline and declarative routing.
