# Environment Setup — MCQs

> Owner: **Shubham Narware**

### Installation {#installation}
1. Which command checks installed Node version? (a) `node --check` (b) **`node -v`** (c) `npm version` (d) `node version` — *Correct: (b).*
2. `nvm` primarily helps you: (a) Install npm packages (b) **Manage multiple Node versions** (c) Debug code (d) Format code — *Correct: (b).*
3. Node's package manager is called: (a) yarn (b) **npm** (c) pip (d) composer — *Correct: (b), bundled by default (Yarn/pnpm are alternatives).*

### VS Code {#vscode}
1. VS Code was released by: (a) Google (b) **Microsoft** (c) Meta (d) JetBrains — *Correct: (b), in 2015.*
2. VS Code's debugger config file is: (a) `debug.json` (b) **`launch.json`** (c) `vscode.json` (d) `config.json` — *Correct: (b).*
3. VS Code type-checks plain JS using: (a) Babel (b) **TypeScript Language Server** (c) ESLint only (d) Webpack — *Correct: (b).*

### Node {#node}
1. Node.js pairs V8 with which library for async I/O? (a) **libuv** (b) libevent (c) asyncio (d) Netty — *Correct: (a).*
2. Node's traditional module system is: (a) ES Modules (b) **CommonJS** (c) AMD (d) UMD — *Correct: (b), though ES Modules are now also supported.*
3. Node.js was created in: (a) 2005 (b) **2009** (c) 2012 (d) 2015 — *Correct: (b), by Ryan Dahl.*

### NPM {#npm}
1. Which file locks exact installed versions? (a) `package.json` (b) **`package-lock.json`** (c) `.npmrc` (d) `node_modules.json` — *Correct: (b).*
2. `npm ci` differs from `npm install` by being: (a) Slower but safer (b) **Faster, exact lockfile-based install** (c) Only for global packages (d) Deprecated — *Correct: (b).*
3. The `^` symbol in a version range allows: (a) Exact version only (b) Patch updates only (c) **Minor and patch updates** (d) Any major version — *Correct: (c).*

### Extensions {#extensions}
1. Extensions run inside a separate: (a) Renderer thread (b) **Extension Host process** (c) Sandbox VM (d) Worker pool — *Correct: (b).*
2. Which extension auto-formats code on save? (a) ESLint (b) **Prettier** (c) GitLens (d) Live Server — *Correct: (b), (ESLint focuses on catching issues, not formatting alone).*
3. `.vscode/extensions.json` is used to: (a) Store secrets (b) **Recommend extensions to the team** (c) Configure the debugger (d) Store snippets — *Correct: (b).*

### Debugging {#debugging}
1. Which flag attaches Chrome DevTools to Node? (a) `--debug` (b) **`--inspect`** (c) `--trace` (d) `--devtools` — *Correct: (b).*
2. `debugger;` pauses execution: (a) Always, even without DevTools open (b) **Only when a debugger is attached** (c) Only in Node (d) Only in production — *Correct: (b).*
3. `console.table()` is best for: (a) Logging strings (b) **Viewing arrays/objects in tabular form** (c) Measuring performance (d) Tracing errors — *Correct: (b).*
