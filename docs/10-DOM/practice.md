# DOM Manipulation — Coding Practice

> Owner: **Shubham Narware**

### Dom {#dom}
- **Easy:** Select an element by id and change its text content.
- **Medium:** Create a new element, set its content, and append it to an existing list.
- **Hard:** Write a function updating multiple elements matching a class in one batch operation.

### Selectors {#selectors}
- **Easy:** Select an element by class and log its text content.
- **Medium:** Select all elements with a `data-active` attribute and add a class to each.
- **Hard:** Demonstrate the difference between a live HTMLCollection and a static NodeList.

### Traversing {#traversing}
- **Easy:** Select an element and log its parent's tag name.
- **Medium:** Remove a card element when its close button is clicked, using `parentElement`.
- **Hard:** Write a manual `findAncestorWithClass(el, className)` function without `.closest()`.
