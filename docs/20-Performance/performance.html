Performance

✅ Complete

Definition

JavaScript performance refers to how efficiently code executes and how responsive an application feels — covering execution speed, memory usage, and rendering smoothness.

Why Performance Matters

Slow JavaScript directly hurts user experience — janky scrolling, unresponsive clicks, and slow page loads all drive users away.

Syntax

const start = performance.now();
doExpensiveWork();
const end = performance.now();
console.log(`Took ${end - start}ms`);

Examples

function memoize(fn) {
  const cache = new Map();
  return (arg) => {
    if (cache.has(arg)) return cache.get(arg);
    const result = fn(arg);
    cache.set(arg, result);
    return result;
  };
}

Diagrams

Performance budget: Load time ──► under ~2-3s for good UX Frame time ──► under ~16ms for 60fps Memory ──► stable over time (no leaks)

Internal Working

Modern JS engines use a JIT compiler that optimizes "hot" code paths — writing predictable, monomorphic code helps the engine optimize more effectively.

Common Mistakes

  • Optimizing without first measuring where the bottleneck actually is.
  • Querying/manipulating the DOM repeatedly inside a loop.
  • Ignoring gradual memory growth leading to degrading performance.

Summary

JavaScript performance spans load time, runtime responsiveness, and memory efficiency — best improved by measuring first, then applying targeted techniques.
