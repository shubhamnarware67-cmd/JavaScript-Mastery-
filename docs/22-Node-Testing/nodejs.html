Node.js

✅ Complete

Definition

Node.js is a JavaScript runtime built on Chrome's V8 engine that lets JavaScript run outside the browser — on servers, CLI tools, and desktop apps.

Why Node.js Matters

It let developers use one language across frontend and backend, and its non-blocking I/O model is efficient for I/O-heavy workloads.

Syntax

const http = require("http");
const server = http.createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "text/plain" });
  res.end("Hello from Node.js!");
});
server.listen(3000);

Examples

const fs = require("fs/promises");
async function readConfig() {
  const data = await fs.readFile("config.json", "utf8");
  return JSON.parse(data);
}

Diagrams

Node.js Runtime = V8 Engine + libuv (event loop, async I/O) + Node APIs │ Single-threaded JS execution, I/O offloaded and non-blocking

Internal Working

Node.js pairs V8 with libuv, a C library providing the event loop and thread pool for async operations.

Common Mistakes

  • Running CPU-intensive synchronous code that blocks Node's single thread.
  • Mixing callback-based and Promise-based APIs inconsistently.
  • Forgetting require() and import need different configuration.

Summary

Node.js lets JavaScript run outside the browser with an efficient, non-blocking I/O model, well-suited for I/O-heavy applications.
