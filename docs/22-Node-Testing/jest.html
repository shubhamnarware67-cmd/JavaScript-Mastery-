Jest

✅ Complete

Definition

Jest is a popular, batteries-included JavaScript testing framework — providing a test runner, assertion library, and mocking utilities in one package.

Why Jest Matters

It bundles everything needed for testing into a single tool with sensible defaults, reducing setup friction.

Syntax

test("description", () => {
  expect(actualValue).toBe(expectedValue);
});

describe("a group of related tests", () => {
  test("first test", () => { /* ... */ });
});

Examples

test("fetchUser resolves with user data", () => {
  return expect(fetchUser(1)).resolves.toEqual({ id: 1, name: "Alex" });
});

Diagrams

Jest Test File describe("Calculator") { test("adds numbers") { expect(...).toBe(...) } } │ Jest runner discovers, executes, reports pass/fail

Internal Working

Jest runs test files in isolated environments for speed, and its mocking (jest.fn()) replaces real implementations with trackable stand-ins.

Common Mistakes

  • Using .toBe() to compare objects/arrays instead of .toEqual().
  • Forgetting to await/return a Promise-based assertion.
  • Not resetting mocks between tests.

Summary

Jest is an all-in-one JavaScript testing framework, widely used for its simplicity and comprehensive feature set.
