Async Await

✅ Complete

Definition

async/await lets Promise-based code read like synchronous code — async marks a function as always returning a Promise; await pauses execution within it until a Promise settles.

Why Async/Await Matters

It removes much of the visual nesting and chaining boilerplate of raw .then() chains, making async code easier to read and reason about.

Syntax

async function fetchData() {
  const result = await somePromise;
  return result;
}

Examples

async function getUser() {
  const response = await fetch("/api/user");
  return response.json();
}

Diagrams

async function ──► always returns a Promise │ await promise ──► pauses function execution │ Promise settles ──► function resumes with the resolved value

Internal Working

Under the hood, async/await is syntax sugar over Promises — each await point splits the function so the code after it runs as a microtask once the awaited Promise settles.

Common Mistakes

  • Forgetting to wrap await calls in try...catch for error handling.
  • Using sequential await calls when the operations could run in parallel with Promise.all().
  • Forgetting an async function always returns a Promise, even if you don't explicitly return one.

Summary

async/await makes Promise-based code read like synchronous code, built as syntax sugar over Promises introduced in ES2017.
