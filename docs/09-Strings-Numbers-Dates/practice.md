# Strings, Numbers & Dates — Coding Practice

> Owner: **Shubham Narware**

### Strings {#strings}
- **Easy:** Write a function that reverses a string.
- **Medium:** Write a function checking if a string is a palindrome.
- **Hard:** Write a `slugify(title)` function converting a title into a URL-friendly slug.

### Template Literals {#template-literals}
- **Easy:** Rewrite a `+`-concatenated string as a template literal.
- **Medium:** Build a multi-line email template string using a template literal.
- **Hard:** Write a tagged template function that highlights interpolated values (wraps them in `**`).

### Numbers {#numbers}
- **Easy:** Write a function formatting a number to 2 decimal places.
- **Medium:** Write a function safely parsing a string to a number, returning `null` on failure.
- **Hard:** Demonstrate precision loss beyond `Number.MAX_SAFE_INTEGER`.

### Math {#math}
- **Easy:** Write a function rounding a number to 2 decimal places using `Math`.
- **Medium:** Write `randomInt(min, max)` producing an inclusive random integer range.
- **Hard:** Write `clamp(value, min, max)` and use it for a game character's health bar.

### Date {#date}
- **Easy:** Create a `Date` for a specific day, log year/month/day correctly.
- **Medium:** Write a function computing days between two dates.
- **Hard:** Write a function formatting a date as "X days ago"/"in X days" relative to now.

### Intl {#intl}
- **Easy:** Format a number as USD currency using `Intl.NumberFormat`.
- **Medium:** Format the current date for `"en-US"` and `"en-GB"`, noting the difference.
- **Hard:** Use `Intl.RelativeTimeFormat` to build a "time ago" utility for timestamped comments.
