Proxy

✅ Complete

Definition

Proxy is an object that wraps another object (the "target") and lets you intercept and customize fundamental operations on it via configurable "traps."

Why Proxy Matters

It enables powerful patterns like validation, logging, reactive data-binding (used by Vue 3), and virtual objects.

Syntax

const proxy = new Proxy(target, handler);
// handler = { get(target, prop) {...}, set(target, prop, value) {...} }

Examples

const target = { name: "Alex" };
const handler = {
  get(obj, prop) {
    console.log(`Accessing ${prop}`);
    return obj[prop];
  },
};
const proxy = new Proxy(target, handler);
proxy.name; // logs "Accessing name", returns "Alex"

Diagrams

Proxy(target, handler) │ Every operation (get, set, delete) on the proxy │ Passes through the corresponding trap in handler

Internal Working

Traps intercept operations at the language level; traps commonly use Reflect internally to perform the default operation while adding custom logic.

Common Mistakes

  • Forgetting set traps must return true on success.
  • Overusing Proxy for simple cases where a plain getter/setter would be clearer.
  • Not using Reflect inside traps, breaking inheritance chains.

Summary

Proxy wraps a target object and lets you intercept fundamental operations via traps, enabling meta-programming patterns like validation and reactivity.
