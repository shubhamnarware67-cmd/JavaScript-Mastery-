Import

✅ Complete

Definition

The import statement (or dynamic import() function) brings exported bindings — variables, functions, classes — from another module into the current file's scope.

Why Import Matters

It gives explicit, traceable control over dependencies — you can see exactly what a file relies on just by reading its import statements.

Syntax

import { name1, name2 } from "./module.js";
import defaultExport from "./module.js";
import * as everything from "./module.js";
const module = await import("./module.js"); // dynamic

Examples

import { PI, square } from "./utils.js";
console.log(square(PI));

// Conditional dynamic import
async function loadAnalytics(userOptedIn) {
  if (userOptedIn) {
    const analytics = await import("./analytics.js");
    analytics.init();
  }
}

Diagrams

import { add } from "./math.js" │ Resolves to math.js's exported `add` binding │ Live reference — updates if math.js's `add` changes

Internal Working

Static import statements are hoisted and resolved at parse time, which is why they must appear at the top level — dynamic import() returns a Promise and can be called anywhere.

Common Mistakes

  • Trying to place a static import inside an if block (only dynamic import() supports this).
  • Confusing named imports with default imports, causing undefined values.
  • Forgetting dynamic import() returns a Promise, requiring await.

Summary

import brings exported bindings into scope — as static imports (hoisted, top-level only) or dynamic import() (a Promise-returning function) for lazy-loading modules on demand.
