# Security — Coding Practice

> Owner: **Shubham Narware** · Status: ✅ Complete

### Security {#security}
1. **(Easy)** Rewrite an `innerHTML` assignment of user input to use `textContent` instead.
2. **(Medium)** Explain how a CSRF token is included in a form submission and validated.
3. **(Hard)** Draft a basic Content-Security-Policy header for a page loading scripts only from its own origin.

### CORS {#cors}
1. **(Easy)** Explain what response header allows a specific frontend origin to fetch data.
2. **(Medium)** Explain what triggers a CORS preflight request using a custom header example.
3. **(Hard)** Configure a credentialed CORS request and describe client and server requirements.

### CSRF {#csrf}
1. **(Easy)** Explain how a CSRF token is generated, embedded, and validated.
2. **(Medium)** Explain how `SameSite=Strict` vs `Lax` differ in CSRF protection.
3. **(Hard)** Describe the double-submit cookie CSRF defense pattern step by step.

### XSS {#xss}
1. **(Easy)** Rewrite an `innerHTML`-based render of user input to use `textContent`.
2. **(Medium)** Explain how Reflected XSS could occur via a search query parameter.
3. **(Hard)** Use a sanitization library concept to safely render rich-text input needing some HTML formatting.
